📘 Tutorial Center / Sentro ng Gabay

Learn the app one step at a time. / Alamin ang app nang paisa-isang hakbang. Place names remain exactly as shown in the app. / Hindi isinasalin ang mga pangalan ng lugar.

Start here / Dito magsimula: Choose a boarding point, choose a destination, then review the fare. / Pumili ng sakayan, pumili ng babaan, at tingnan ang pamasahe.
1. Main fare calculator / Pangunahing pagkukuwenta

EN: Tap the BOARDING POINT control and choose where the trip starts. Tap DESTINATION and choose where you will get off. The fare panel updates after both places are selected.

TL: I-tap ang BOARDING POINT at piliin kung saan magsisimula ang biyahe. I-tap ang DESTINATION at piliin kung saan bababa. Mag-a-update ang pamasahe kapag napili na ang dalawang lugar.

EN: Use the search field to find a place; tap an exact result. Use the clear (×) control to clear the search text.

TL: Gamitin ang search field para hanapin ang lugar; i-tap ang tamang resulta. Gamitin ang (×) para burahin ang text sa search.

2. Add a place / Magdagdag ng lugar

EN: Open Settings → Add place. Enter the place name, choose its assigned fare area, then tap Save place. The place becomes searchable. Use the exact spelling you want displayed.

TL: Buksan ang Settings → Add place. Ilagay ang pangalan ng lugar, piliin ang fare area nito, at i-tap ang Save place. Maaari na itong hanapin. Gamitin ang eksaktong baybay na gusto mong makita.

EN: Do not rename an existing place just to change its fare; use the Fare editor for fare changes.

TL: Huwag palitan ang pangalan ng lugar para lang baguhin ang pamasahe; gamitin ang Fare editor para sa pamasahe.

3. Edit or remove a custom place / Baguhin o alisin ang custom place

EN: Open Settings → Edit places. Search for the place, then use its ✏️ edit control to change its details or its delete control to remove it. Read the confirmation prompt before confirming.

TL: Buksan ang Settings → Edit places. Hanapin ang lugar, pagkatapos gamitin ang ✏️ para baguhin ang detalye o ang delete control para alisin ito. Basahin muna ang confirmation bago magpatuloy.

EN: Editing a place name may update saved fare references. Check the displayed place and route fares afterward.

TL: Ang pagpapalit ng pangalan ay maaaring mag-update ng mga naka-save na fare reference. Suriin muli ang lugar at route fares pagkatapos.

4. Fare areas and fare editor / Fare areas at pag-edit ng pamasahe

EN: Open Settings → Fare editor. Search for a place to find its area fare. For a specific route, choose the boarding point and destination, enter the Regular and Student / Senior / PWD amounts, choose whether the return trip uses the same fare, then save the route fare.

TL: Buksan ang Settings → Fare editor. Maghanap ng lugar para makita ang pamasahe ng area nito. Para sa partikular na ruta, piliin ang sakayan at babaan, ilagay ang Regular at Student / Senior / PWD na halaga, piliin kung pareho ang pamasahe sa pabalik, at i-save ang route fare.

EN: Review the existing saved fare panel before changing anything. The fare audit notice helps identify same-price areas. Only save values you have verified.

TL: Tingnan muna ang existing saved fare panel bago magbago. Tumutulong ang fare audit notice na makita ang mga area na magkakapareho ang presyo. I-save lamang ang mga halagang napatunayan mo.

5. GPS ON / OFF / Paggamit ng GPS

EN: Tap the 📍 GPS button to turn location assistance ON. Allow location permission when the phone asks. Tap it again to turn GPS OFF. GPS does not automatically turn on when the app launches.

TL: I-tap ang 📍 GPS button para i-ON ang location assistance. Payagan ang location permission kapag nagtanong ang phone. I-tap muli para i-OFF ang GPS. Hindi ito kusang nag-o-ON sa pagbukas ng app.

EN: If location is unavailable, check phone Location settings and browser/app permission. GPS may require a supported browser or app environment.

TL: Kung walang location, tingnan ang Location settings ng phone at pahintulot ng browser/app. Maaaring kailangan ng suportadong browser o app environment.

6. SOLO and GROUP / SOLO at GROUP

EN: Use the person/mode button to switch between SOLO and GROUP. SOLO is for one passenger. GROUP is for a group trip; follow the passenger and boarding-point prompts shown by the app.

TL: Gamitin ang person/mode button para lumipat sa SOLO at GROUP. Para sa isang pasahero ang SOLO. Para sa magkakasamang pasahero ang GROUP; sundin ang mga passenger at boarding-point prompt ng app.

7. Discounts and passenger type / Discount at uri ng pasahero

EN: Select the applicable passenger type in the passenger controls before relying on the displayed discounted fare. Check that the route has a saved discount fare in Fare editor. Do not assume every route has the same discount amount.

TL: Piliin ang naaangkop na passenger type sa passenger controls bago gamitin ang discounted fare. Tiyaking may naka-save na discount fare ang ruta sa Fare editor. Huwag ipagpalagay na pare-pareho ang discount sa lahat ng ruta.

8. Payment and change / Bayad at sukli

EN: After the fare is shown, use the payment amount field in the payment panel. Enter the amount received; the app calculates the change when the amount is sufficient. Recheck the fare, passenger count/type, and amount received before handing over change.

TL: Kapag lumabas na ang pamasahe, gamitin ang payment amount field sa payment panel. Ilagay ang natanggap na bayad; kukuwentahin ng app ang sukli kapag sapat ang halaga. Suriin muli ang pamasahe, bilang/uri ng pasahero, at natanggap na bayad bago magbigay ng sukli.

9. Backup and restore / Backup at restore

EN: Open the Additional tools (🧰 TOOLS) panel and locate the backup/restore controls. Export a backup before major edits or moving to another device. Keep the downloaded backup file somewhere safe.

TL: Buksan ang Additional tools (🧰 TOOLS) at hanapin ang backup/restore controls. Mag-export ng backup bago gumawa ng malalaking pagbabago o lumipat ng device. Itago sa ligtas na lugar ang na-download na backup file.

EN: Restore replaces local app data with the backup contents. The app creates a safety backup before restoring. Choose only a backup file you trust and confirm carefully.

TL: Pinapalitan ng Restore ang local app data gamit ang laman ng backup. Gumagawa muna ang app ng safety backup bago mag-restore. Pumili lamang ng mapagkakatiwalaang backup file at mag-confirm nang maingat.

10. Themes, language, and display / Tema, wika, at display

EN: In Settings → Language, choose Filipino or English. In Themes and design, preview available color/design settings and save them. Use the dark-mode button in Additional tools to switch the display theme if available.

TL: Sa Settings → Language, piliin ang Filipino o English. Sa Themes and design, i-preview ang mga kulay/disenyo at i-save. Gamitin ang dark-mode button sa Additional tools para palitan ang display theme kung available.

11. Extra tools, history, audit, and safety / Dagdag na tools, history, audit, at safety

EN: Open 🧰 TOOLS to see the additional utilities available in this edition, such as fare history, undo, fare audit, batch fare calculation, accessibility/one-hand options, and Safety Lock. Each tool has its own on-screen label and confirmation. Review the displayed details before applying a change.

TL: Buksan ang 🧰 TOOLS para makita ang mga dagdag na utility sa edition na ito, gaya ng fare history, undo, fare audit, batch fare calculation, accessibility/one-hand options, at Safety Lock. May sariling label at confirmation ang bawat tool. Suriin ang detalye bago maglapat ng pagbabago.

EN: Safety Lock can suppress uncertain or unverified fares. Treat warnings as a reason to verify the fare against your trusted fare record.

TL: Maaaring itago ng Safety Lock ang mga hindi tiyak o hindi pa beripikadong pamasahe. Kapag may warning, beripikahin ang pamasahe gamit ang mapagkakatiwalaang fare record.

12. Quick troubleshooting / Mabilisang pag-aayos

EN: If a place is missing, check the search spelling and Settings → Edit places. If a fare looks wrong, verify the selected boarding/destination, passenger type, route override, and fare area. If GPS fails, check permissions. If data matters, export a backup before troubleshooting.

TL: Kung walang lumalabas na lugar, tingnan ang spelling sa search at Settings → Edit places. Kung mali ang pamasahe, tiyakin ang sakayan/babaan, passenger type, route override, at fare area. Kung pumalya ang GPS, tingnan ang permissions. Kung mahalaga ang data, mag-export muna ng backup bago mag-troubleshoot.

Reminder / Paalala: Tutorial text explains the controls; the actual saved fare records and app calculations remain in the existing app. Always verify fares before collecting payment. / Gabay lamang ang tutorial na ito; nananatili sa app ang kasalukuyang fare records at calculations. Laging tiyakin ang pamasahe bago maningil.
